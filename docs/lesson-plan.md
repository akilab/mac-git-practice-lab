# Git教材プラン

GitHubを基準に説明し、最後にGitLabとの差分を紹介します。

## 章立て案

1. GitとGitHubの違い
2. repository / clone / remote
3. working tree / staging area / commit
4. branchを作って作業する
5. diffで変更を見る
6. addとcommit
7. pushしてPull Requestを作る
8. mainへ取り込まれた後のpull
9. restoreで安全に戻す
10. GitHubとGitLabの違い

## 教材で重視すること

- 初学者には `git status` を何度も見せる
- `main` で直接作業しない習慣を作る
- `git add .` より先に `git diff` を見る
- `reset --hard` は最初の教材では扱わない
- GitLabは最後に差分として説明する
